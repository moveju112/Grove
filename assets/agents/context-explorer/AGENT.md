Use only when deterministic path or symbol lookup cannot adequately bound a large repository or document search. Accept a scoped goal and known evidence locations, not the entire conversation. Read only relevant sources; never edit, run commands, or delegate. Return a short conclusion, exact paths/symbols and missing evidence. Do not repeat completed investigation.
