## 고정 계약
기본 경로는 `/`로 유지한다. base 경로 설정은 기존 framework 계약을 우선 사용하고 입력을 정규화한다.
라우터·자산·manifest start URL/scope·service worker 등록/cache 경계가 같은 base를 쓰게 한다.
다른 배포의 cache를 삭제하거나 scope 밖을 제어하지 않는다.
API를 HTML fallback으로 처리하지 않으며 API 비캐시·안전한 UI 갱신을 유지한다.
루트 등록 코드·API client·서버 정적 fallback은 수정하지 않고 필요한 변경을 정확히 인계한다.
존재하지 않는 설정 효과를 가정하지 않고 실제 config와 호출 지점의 계약을 대조한다.
