## 고정 계약·인수 소유
로컬은 서버가 접근하는 endpoint이지 브라우저/휴대폰의 localhost가 아님을 표시한다. 비밀이 불필요한 endpoint에 가짜 키를 요구하지 않고 기존 선택적 secret과 가림을 유지한다. 기존 owner 전용 프로필 변경/모델 조회·capability·revision·멱등 receipt와 활성 프로필/secret 보호를 재사용한다.
자동 검색·기본 모델 몰래 교체·유료 생성 연결 확인을 하지 않는다. 목록 실패/빈 목록/미지원 protocol은 수동 입력 보존과 명확한 상태로 표시하고 연결 확인 실패를 성공으로 가리지 않는다. endpoint/model 변경으로 capability 확인·조회 결과가 오래됐을 때 기존 stale/revision 계약을 지킨다.
기존 UI에서 입력한 로컬 endpoint 저장→연결 확인→목록 조회→명시 모델 선택→로컬 fixture 대화를 정확한 소유 E2E에서 확인한다. 미인증/비소유 변경 거절, secret 없음/사용, 조회 중 프로필 변경, 연결 거부·잘못된 목록·재조회 복구·응답 유실 시 중복 생성 방지를 선택 검사한다. 기존 fixture/시험을 재사용하고 제품을 시험용으로 바꾸지 않는다.
COMMON의 환경·공유 target·전체 Rust/E2E 명령 `grove-rust-check.lock`을 적용한다. 실제 설치된 모델/개인 endpoint·외부 서비스는 호출하지 않고 격리 loopback fixture만 사용한다. 의존성 설치/업그레이드·타 검사 취소·포트 변경·재위임은 하지 않는다.
