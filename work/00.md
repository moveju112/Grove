## 고정 계약
외부 클라이언트의 임의 파일 경로를 받아 여는 API를 만들지 않는다.
조회 모듈은 서버에서 결정된 source root와 식별자를 입력받는다. 실제 인증·root 결정·라우트는 통합 담당 소유다.
결과는 source, 존재/부재/읽기 실패/미지원 형식 상태, 지원한 안전 필드의 projection이다.
출처 표시만으로 Grove에 적용됐다고 표시하지 않는다. 적용 기능은 추가하지 않는다.
파일 전체 원문·환경 변수·토큰·자격증명·명령 문자열을 응답하거나 로그에 남기지 않는다.
명시적으로 허용한 필드만 표시하고 알 수 없는 필드는 버린다.
JSON은 기존 serde_json을 재사용한다. 전용 parser가 없는 형식은 미지원으로 표시하고 임의 문자열 파싱으로 설정을 추측하지 않는다.
실제 개인 설정을 fixture로 복사하지 않고 최소 비밀 없는 fixture를 사용한다.
UI는 projection을 props로 받아 출처·제한·오류를 표시한다.
