## 사용자 명시 후속: 공유 환경 복구와 역할 내 검증 완료
현재 원래 세션 `684c9ba6-fe86-479f-bd81-ade1a401079e`를 그대로 재개한다. 시스템 오류 재시도가 아니며 기존 retry count를 수정하지 않는다. 제품/인계 기준은 기존 `b6671ea`다.
메인 `web/node_modules`에서 react-router·vitest·typescript resolve가 성공했고, 이 worktree의 react-router resolve만 MODULE_NOT_FOUND였다. 설치·복사·upgrade 없이 COMMON의 기존 shared node_modules·필요한 .dev ignored symlink를 직접 연결하고 소유 웹 타입·단위 시험을 끝낸다. 기존 유효한 Rust 23개 근거는 재사용한다.
이 후속은 소유 E2E 실행도 명시적으로 허용한다. `source`한 공통 빌드 환경과 기존 선택 실행기를 사용하고, **전체 E2E 명령을 `flock /home/ubuntu/.cache/grove-rust-check.lock` 안에서 실행**해 현재 메인 검증 및 다른 E2E와 겹치지 않게 한다. 임의 포트 변경·검사 생략·의존성 설치로 우회하지 않는다. 검증 실패는 소유 범위에서 고치고 영향받는 검사만 다시 실행한다.
분배 가능한 구현·연결·검사를 다 끝내기 전에 단순 통합 대기로 종료하지 않는다. 남은 검증이 자원 대기라면 이를 완료나 외부 blocker로 바꾸지 않는다.
Codex inline TOML은 Cargo.toml·Cargo.lock에 승인된 전용 parser가 없고 dependency 추가 권한도 없다는 실제 경계다. 임의 parser·신규 dependency를 만들지 말고 unsupported 표시, 정확한 미충족 요구와 parser 승인/연결이라는 해제 조건을 보존한다. 가능한 검증을 마친 뒤에는 이 실제 blocker와 역할 내 완료 근거를 분리해 RESULT에 커밋한다. 마이크/STT 제외 및 원문·비밀값 비노출 계약은 그대로다.
