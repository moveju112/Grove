## 계약·검증 소유
업데이트는 읽기/비교만으로 override를 덮어쓰지 않는다. 사용자 정의(non-builtin), 이름·설명·본문·enabled와 기존 수명/삭제 규칙을 보존한다. 선택 적용은 명시한 필드만 현재 번들 기본값으로 바꾸며 선택하지 않은 필드·활성 상태·미저장 초안을 잃지 않는다. 취소는 mutation하지 않는다. 비교 UI는 원문을 text로 렌더하고 외부 HTML 실행을 허용하지 않는다.
현재 revision 및 비교한 baseline identity가 바뀌면 확인 전의 다른 기본값을 조용히 적용하지 않는다. 기존 idem receipt·오류 형식·권한 계약을 유지하고 서버 검증이 필요하면 기존 restore의 좁은 확장으로 해결한다. 응답 유실·동시 사용자 편집·재시작 시 같은 요청을 중복 적용하거나 stale 값을 덮어쓰지 않는다.
기존 definitions fixture/저장소를 재사용해 이전 버전에서 저장된 override와 현재 builtin을 비교·보존하는 상황을 검증한다. 실제 번들 원문·개인 DB를 바꾸거나 updater를 실행하지 않는다. 기존 API만으로 요구를 충족하면 새 schema/route 없이 UI와 증거를 완성한다.
브라우저 소유는 정확히 신규 `e2e/definition-updates.spec.ts`: 수정본 보존→비교→필드별 적용→미선택/disabled 유지→reload와 취소·stale/revision·응답 유실 복구다. 필수 Rust·웹 선택 검사와 실제 브라우저 인수를 자기 workspace에서 끝낸다. COMMON의 공유 환경·target·전체 Rust/E2E 명령 `grove-rust-check.lock`을 적용한다. 타 검사·포트·의존성·타 세션은 변경하지 않는다.
