## 고정 계약
자동 stash·reset·clean·checkout으로 사용자 변경을 버리지 않는다는 기존 원칙(`src/git.rs` 머리 주석, `GIT-006`)을 유지한다. 모든 동작은 사용자가 명시적으로 시작한다.
discard·pop 충돌 가능 동작은 대상 경로·변경 요약을 보여 주는 확인 단계를 거치고, 확인 시점과 실행 시점의 상태(fingerprint)가 다르면 실행하지 않는다.
untracked 파일 삭제는 별도 확인 없이 포함하지 않는다.
pop 충돌은 stash를 보존하고 충돌 상태를 그대로 보고한다.
프로젝트 접근 권한과 경로 검증(`..`·절대 경로·옵션 주입)을 기존 함수로 재사용한다.
