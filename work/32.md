## 계약
생성 당시 프로필 표시 이름·protocol·실제 model, 가격표 통화/version을 기록한다. 전체 options·endpoint 자격·secret은 복제하지 않는다.
비용은 기존 계산기의 생성 당시 가격표 기준 추정치다. 가격·usage 없음은 미기록/추정 불가로 표시하고 0원으로 꾸미지 않는다.
기존 note에 현재 프로필 값을 과거 실행값으로 소급하지 않는다. 프로필 변경/삭제 뒤에도 저장한 공개 기록을 유지한다.
원문 이동은 저장된 범위의 실제 메시지를 기존 focus/pagination으로 찾아가며 사라진 대상은 이동 불가로 알린다. 모델 context 복원을 뜻하지 않는다.
인증·summary 모델 선택·FAIR auxiliary 슬롯·취소·source hash·timeline revision·중복 범위 검사를 보존하고 mutation 자동 retry를 추가하지 않는다.
압축 품질 비교(CMP-013), 새 dependency·외부 모델 호출은 제외한다.
