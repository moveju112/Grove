## 고정 계약·선택 인수
직접 실행의 허용/승인/deny/read_only·등록된 실제 schema 검증을 로딩 여부로 우회하지 않는다. 조회가 다른 도구 실행·승인·MCP 원격 조회를 암묵적으로 일으키지 않으며 임의 schema/path/명령을 등록받지 않는다. 없는 도구·잘못된 인자·조회량 초과는 기존 명시적 오류로 반환한다. 현재 제공 불가능한 도구를 사용 가능하다고 안내하지 않는다.
선택 범위·조회량은 유한하게 제한하고 선택된 이름을 정규화해 결정적인 순서로 모델 요청에 반영한다. 도구 result/call 짝·모델별 서명 격리·native provider 변환·context 입력 용량/출력 여유·tools=false·CLI 제한을 유지한다. 재시작·응답 유실·재접속이 이미 실행된 부작용 도구를 재실행하면 안 된다.
기존 모델 fixture에서 처음 요청의 제한된 schema→지연 로딩 tool call/result→다음 요청에 실제 schema→기존 승인 도구 실행→결과 표시를 확인한다. 같은 집합의 요청 순서 안정성·알 수 없는 이름/정책 금지·tools off/CLI·취소/복구·fallback 후보별 도구 capability를 선택 검사한다. 기존 회귀를 재사용하며 전체 도구 테스트를 불필요하게 반복하지 않는다.
배정된 실제 브라우저 소유는 신규 `e2e/deferred-tools.spec.ts`의 이 흐름이다. 서버/API/모델 요청의 관측을 fixture로 확인하고 실제 유료 모델·외부 MCP·개인 데이터는 사용하지 않는다. COMMON의 공유 환경·target·전체 Rust/E2E 명령 잠금을 적용한다.

## 완료
필요한 내장 도구 schema를 턴 안에서 제한적으로 로딩해 실제 다음 모델 요청과 승인된 실행까지 이어지고, 같은 선택의 모델 입력이 안정적이며 권한·context·취소·복구 경계를 보존하는 상태다. 실행 가능한 소유 잔여와 브라우저 인수를 끝내고 `grove-handoff:v1`과 실제 blocker(reason/unblock)를 RESULT에 남긴다. 관련 한국어 로컬 커밋 뒤 종료하며 TODO 체크·merge·push·배포·workspace 정리·재위임은 하지 않는다.
