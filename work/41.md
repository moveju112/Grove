## 표시·권한·복구 계약
기본/사용자 정의·수정 override·비활성 상태와 지침 원문은 서버 resolver의 현재 적용값을 사용한다. 이름으로 역할·모델·capability를 추측하지 않는다. 등록된 역할과 현재 정책상 사용 가능한 역할을 구분하고, 모르는 상태/조회 오류를 비활성 또는 성공으로 가리지 않는다.
모델은 현재 부모 턴을 상속하는 실제 계약과 다음 요청의 범위별 `model.default_profile` 설정을 구분한다. 기본값이 없거나 삭제/비활성이면 미설정·선택 필요로 표시하고 임의 첫 모델을 연결하지 않는다. 역할별 고정 모델·context/disabled 설정이 구현됐다고 표시하지 않는다.
`agents.delegation`·실제 상수 한도·부모 취소/재시작 비재실행 규칙을 현재 구현과 대조해 안내한다. role 원문·모델 이름/endpoint 표시에서 secret 원문·인증 헤더·개인 경로를 노출하지 않는다. 읽기 권한은 기존 인증·scope 계약보다 넓히지 않는다.
프로젝트/대화에서 연 화면 대상은 고정하고 다른 pane 선택으로 바뀌지 않는다. unmount·응답 순서 변경·재접속·조회 실패에서 이전 대상 정보를 새 대상의 실제 설정처럼 표시하지 않는다. 개요 열기/원문 확인만으로 설정 저장·자식/모델 실행·템플릿 설치를 하지 않는다.
기존 API·fixture/시험을 재사용해 범위별 설정·builtin/override·disabled·모델 미설정·인증 거부·오류 복구를 확인한다. 배정 브라우저 소유는 신규 `e2e/agent-overview.spec.ts`의 개요→지침/기존 편집→reload·대상 보존 흐름이다. COMMON의 공유 환경·target·전체 Rust/E2E 명령 잠금을 따른다.
