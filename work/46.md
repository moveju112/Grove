## 실제 인수·안전
소유 임시 project/run 디렉터리·loopback 모델과 안전한 fixture 도구로 실행 중 응답 유실/중단/unknown을 관측한다. unknown을 HTTP 오류나 단순 실행 실패로 대체해 검증하지 않는다. 실제 유료 모델·사용자 계정·외부 서비스·공유 프로세스를 쓰거나 끊지 않는다.
원래 부작용이 반복되지 않음을 표식과 호출 수로 확인하고 CLI 출력 schema·숫자 exit code·run identity·보존 경로를 실제 프로세스에서 검사한다. `exec show`와 반복 조회/재시작은 실행·자동 승인·임시 데이터 삭제를 일으키지 않는다. 비밀·원문·경로가 잘못 노출되지 않게 기존 가림을 유지한다.
선택 검사는 전용 exec_unknown과 필요한 기존 exec 회귀이며 실제 CLI를 사용한다. UI 없는 흐름에 브라우저를 새로 만들지 않는다. COMMON의 환경·공유 전체 Rust/E2E 잠금을 따른다.
완료는 실행 중 unknown이 호환 schema/코드로 관측되고 보존된 결과를 중복 실행 없이 조회하는 상태다. 실행 가능한 잔여를 끝내고 `grove-handoff:v1`·실제 근거·blocker(reason/unblock)를 RESULT에 남긴다. 관련 한국어 로컬 커밋 허용. TODO·merge/rebase·push·배포·재위임·workspace 관리·dependency 변경은 하지 않는다.
