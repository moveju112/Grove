## 고정 계약
서버 승인 Grove 스킬 root만 쓰고 기존 Principal·프로젝트 쓰기 guard·read-only 정책을 재사용한다. client root/path를 권한으로 신뢰하지 않는다.
본문 저장은 expected revision과 기존 파일 경계·원자적 저장·멱등 receipt를 사용해 동시 편집을 덮지 않는다. 원문·경로·비밀값을 이벤트/오류에 추가하지 않는다.
다시 읽기는 현재 파일을 관측할 뿐 기존 세션 선택의 source/revision을 몰래 바꾸지 않는다. 비활성·변경 스킬의 기존 선택은 명시적으로 적용 불가임을 알리고 사용자가 해제/다시 선택한다.
원본 스킬·hook 가져오기, 실행, 자동 매칭, metadata alias/hardlink 정책 확장은 범위 밖이다. 새 dependency나 외부 설치가 없어야 한다.

## 완료
사용자가 Grove 스킬을 추가·저장·reload·켜기/끄기하고 다음 모델 적용 상태를 정확히 확인할 수 있으며 권한·충돌·재시도·기존 선택의 revision 계약이 보존된 상태다.
