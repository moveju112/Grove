이번 범위는 설정과 표시다. 실제 업데이트 설치·서비스 재시작은 하지 않는다. “확인”은 기존 업데이트 확인 경로만 쓰고, 시험은 로컬 fixture 응답을 쓴다(외부 릴리스 서버 접속 금지).
자동 적용 범위 기본값은 “알림만”이다. 진행 중 작업이 있으면 적용을 미룬다는 기존 update-readiness 계약을 화면에 보인다.
소유자만 바꿀 수 있다. 일반 기기는 읽기만 한다.
PWA UI 갱신 안내(14 `WEB-007`)와 서버 업데이트를 화면에서 구분한다.
