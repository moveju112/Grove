# 모든 기능 세션에서 같은 첫 메시지

`work/README.md`의 현재 활성 작업 워크스페이스에서 세션을 열고 아래 메시지를 그대로 보낸다. 초기 00~09 중 06은 취소됐다. 다음 번호도 같은 메시지를 사용한다.
사용자가 문서 번호를 지정하지 않는다. 실제 Git worktree 경로와 브랜치가 번호를 결정한다.
잘못된 번호 문서로 중단한 기존 세션에도 같은 메시지를 보내면 된다.

```text
앞서 번호를 잘못 지정했다면 그 지정은 취소해.
/data/project/paseodog_opus/work/ENTRY.md를 읽고 현재 worktree와 브랜치에 맞는 작업을 자동 선택해서 진행해.
작업 관련 로컬 커밋은 허용하고 push·merge·배포는 하지 마.
완료하면 지정된 인계 파일을 남기고 멈춰.
```

원본 프로젝트에서 실행하면 안전하게 중단한다. 다른 worktree로 자동 이동하지 않는다.
작업자가 작성하는 인계 파일은 자기 worktree의 `work/RESULT-NN.md`다.
기능 세션은 직접 정리하지 않는다. 메인 세션은 아래 절차로 완료 작업을 통합·정리한다.

## 완료된 작업 통합: 00 메인 세션·다른 메인 세션 공통
원본 프로젝트 `/data/project/paseodog_opus`에서 메인 세션 하나를 열고 아래 메시지를 보낸다.
“통합해줘”, “정리해줘”, “합쳐줘”, “10개 뽑아줘”만 보내도 같은 범위로 1~5단계 전체가 실행된다. 아래 메시지는 생략해도 된다.
사용자가 “00 메인 세션”이라고 부르는 세션에서도 사용할 수 있지만, 실제 위치는 위 원본 프로젝트의 `master`여야 한다. 기존 00 원본 설정 기능 worktree에 보내지 않는다. 일부 작업만 끝나도 사용할 수 있다.
```text
/data/project/paseodog_opus/work/INTEGRATE.md를 읽고 완료된 작업만 확인해서 통합해줘.
로컬 통합·필요한 수정·검증·관련 커밋과 TODO 반영까지 진행해.
검증과 인계 보존이 끝난 깨끗한 완료 worktree와 해당 Paseo 워크스페이스만 정리해.
빈 자리에는 겹치지 않는 다음 번호의 기능 문서·worktree·워크스페이스를 준비해줘.
진행 중인 작업은 건드리지 말고, 새 기능 세션은 내가 직접 시작할게.
push·배포·강제 삭제·작업 브랜치 삭제는 하지 마.
```
