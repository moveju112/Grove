## 고정 계약
조회만 제공한다. 쓰기·적용·우선순위 계산을 추가하지 않는다.
root·파일 경로·임의 파일명을 클라이언트 입력으로 받지 않는다. 고정 source 식별자와 인가된 프로젝트 식별자만 받는다.
소유자/관리 권한과 프로젝트 접근 권한을 검사한다. 인증만으로 서버 사용자 원본을 열지 않는다.
동기 filesystem I/O는 blocking 경계에서 실행한다.
화면은 Grove 실제 적용 설정과 원본 조회를 구분해 표시한다. 원문·서버 오류 본문을 노출하지 않는다.

## 완료
설정 화면에서 원본 설정이 실제 API로 표시되고, 인증 거부·다른 프로젝트 거부·root 입력 거부·원문 비노출을 Rust 시험과 E2E로 다룬다.
