## 고정 계약
독립 `AssistantIdentity` 컴포넌트의 props는 name, 선택적 image URL, 표시 크기/용도다.
기존 이름·사진 원천을 읽기 전용으로 조사하고 통합 담당에게 실제 연결 지점을 인계한다.
새 설정 저장소·API·사용자 프로필 편집 기능은 만들지 않는다.
이름은 React 텍스트로 표시하고 HTML을 삽입하지 않는다.
이미지는 기존 인증된 동일 origin 자산 정책에 맞는 경우만 사용한다.
임의 외부 URL·실행 가능한 scheme을 허용해 추적·정보 유출을 만들지 않는다.
없음·로딩 실패·정책 위반이면 안정적인 기본 아이콘을 사용한다. 실패 재시도 루프를 만들지 않는다.
접근 가능한 이름·장식 이미지 구분과 긴 이름·좁은 화면을 처리한다.
