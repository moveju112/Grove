## 요구 선언 형식
기존 YAML front matter를 추측해서 해석하지 않는다. 선택적 같은 스킬 디렉터리의 `requirements.grove.json`만 지원하고, 없으면 기존 동작을 유지한다. schema는 version 1과 유한한 `tools`/`platforms`/`skills` 문자열 배열이다. 등록된 도구 이름·실제 서버 OS·명시적 스킬 이름만 비교한다. 미지 version/키·중복/과도한 항목·잘못된 타입·모호한 이름·순환 의존은 명시적 오류다. 실행 파일 설치·임의 shell probe·네트워크·동적 package 해석은 제외한다.
의존 스킬은 이미 사용자가 선택한 허용 source/revision에서만 충족된다. 프로젝트/전역 우선순위와 동급 충돌 정본을 재사용하고 조용히 선택/대체하지 않는다. manifest 내용도 revision에 결합해 변경/삭제/새로 생김을 stale로 검출한다. 허용 root·bounded UTF-8·일반 파일·symlink 탈출/교체 검사를 본문과 동등하게 적용한다.

## 권한·복구·인수
manifest는 데이터이며 도구 허용·승인·실행을 부여하지 않는다. 읽기 전용 모드·disabled tools·미지원 모델/CLI와 실제 사용 가능한 도구를 확인하되 기존 최종 실행 권한 검사를 대체하지 않는다. 이미 선택된 스킬이 뒤에 불충족이면 모델에 일부만 적용하거나 다음 revision으로 교체하지 않고 기존 오류 계약으로 중단한다. 조회/선택 해제·문제 수정 후 명시적 재선택은 가능해야 한다.
선택·응답 유실·재시작·root/본문/manifest 변경·다른 세션·프로젝트 권한 경계와 source/revision 보존을 격리 fixture로 확인한다. 브라우저 소유는 `e2e/skill-requirements.spec.ts`의 선언 파일→조회 이유→명시적 선택→실제 모델 지침 적용/불충족 거부→reload 비재실행 흐름이다. 실제 사용자 파일·유료 모델·외부 계정은 사용하지 않는다.
COMMON의 공유 환경·전체 Rust/E2E 명령 잠금을 따른다. 완료는 선택 화면의 요구 검증과 실제 모델 적용이 같은 관측 사실에 따르고 권한·선택·복구를 보존하는 상태다. 소유 잔여와 브라우저 인수를 끝내고 RESULT에 `grove-handoff:v1`·실제 blocker(reason/unblock)를 남긴다. 한국어 관련 로컬 커밋은 허용하며 merge·push·배포·재위임·workspace 정리·TODO 체크는 하지 않는다.
