## 고정 계약
편집기 목록은 서버가 정한 고정 후보(이름·실행 파일)에서 실제 존재하는 것만 반환한다. 클라이언트가 실행 파일 경로·인자를 보낼 수 없다.
열기 요청은 편집기 식별자와 프로젝트 상대 경로만 받는다. 기존 프로젝트 경계·경로 검증을 재사용하고 symlink로 프로젝트 밖을 열지 않는다.
프로세스는 shell 없이 인자 배열로 실행하고 분리(detach)한다. 결과를 기다리지 않으며 실행 실패만 보고한다.
서버 사용자에게 GUI 세션이 없으면(예: `DISPLAY`·`WAYLAND_DISPLAY` 없음, Windows 서비스 세션) capability를 끄고 화면에 이유를 표시한다.
쓰기 권한이 있는 사용자만 열 수 있다. 읽기 전용 정책·인증 거부를 기존 권한 검사로 처리한다.
시험은 임시 PATH의 가짜 편집기 실행 파일로 탐지·인자·경계를 확인하고 실제 편집기를 띄우지 않는다.

## 완료
탐지·미탐지·GUI 없음·경로 탈출 거부·권한 거부·가짜 편집기에 전달된 정확한 인자를 Rust 시험으로, capability가 있을 때만 버튼이 보이는 것을 E2E로 확인한다.
