## 범위·실제 연결
`CMP-012`에서 남은 디스크 실패·재시작 주입을 완결한다. `src/context.rs::compact`는 준비 시 source hash/timeline을 고정하고 요약 응답 뒤 transaction에서 CAS로 projection을 저장한다. 기존 `tests/context.rs`의 경합·원문 변경·과대 요약과 `e2e/rewind.spec.ts` 근거를 재사용한다.
소유는 신규 `tests/compaction_faults.rs`, `src/context.rs::compact`의 재현된 저장/실패 처리 최소 수정과 관련 전용 단위 시험, `work/RESULT-45.md`다. 기존 context 회귀를 바꿔야 하면 해당 실패 시나리오만 허용한다. runner/44의 증거 복구·전역 store·provider transport·모델 지침·32 상세 표시·공용 fixture는 읽기 전용이다.
새 설정·schema·route·품질 평가·summary prompt 변경·일반 fault framework는 제외한다. 로컬 모델 fixture와 기존 compact API→history/model-input/원문 조회로 검증한다. 브라우저 변경은 하지 않으며 실제 서버 흐름의 응답 보류/실패/재시작을 관측한다.

## 보존 계약·완료
소유 disposable DB에서 SQLite full/쓰기 거부 또는 확정된 저장 경계 실패를 주입한다. 다른 세션·공유 환경·사용자 파일에 실패를 만들지 않는다. 권한 실패는 실제 거부를 확인한다.
실패·중단 전의 원문·기존 projection과 call/result 짝을 유지한다. 재시작 뒤 구 source/timeline 후보를 적용하거나 provider를 자동 재호출하지 않는다. 실패 상태를 정상 압축 이벤트로 가리거나 기존 회귀의 기대를 낮추지 않는다.
선택 검사는 compaction_faults와 영향을 받은 context/model-input 회귀다. COMMON의 환경·전체 Rust/E2E 잠금·유효 근거 재사용을 따른다.
완료는 실제 저장 실패와 재시작에서도 원문/기존 projection이 유지되고 stale 후보가 거부되는 사용자 흐름이다. 실행 가능한 잔여를 끝내고 RESULT에 `grove-handoff:v1`, 실제 근거·blocker(reason/unblock)를 남긴다. 관련 한국어 로컬 커밋 허용. TODO·merge/rebase·push·배포·재위임·workspace 관리·dependency·EVAL 변경은 하지 않는다.
