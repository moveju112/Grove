## 고정 계약
기존 reqwest·tokio·ToolResult/ToolError를 재사용한다. 새 dependency는 추가하지 않는다.
실행 함수는 args·계획된 대상·cancel을 받아 기존 도구 실행 계약과 연결 가능하게 한다.
HTTP client의 자동 redirect·환경 proxy로 검증을 우회하지 않는다.
최초 URL·각 redirect·실제 연결 IP를 검증하고 DNS 재해석으로 SSRF 방어가 깨지지 않게 한다.
loopback·private·link-local·metadata 등 비공개 대상은 거부한다.
자격 헤더·cookie·사용자 URL 자격정보를 외부로 전달하지 않는다.
응답·압축 해제·출력 크기, redirect 횟수, timeout·취소를 제한한다.
캐시는 인증 없는 공개 요청만 대상으로 유한 크기·수명을 적용하고 금지 요청·실패·민감 응답을 저장하지 않는다.
HTML을 JS 실행 없이 처리한다. 기존 의존성으로 정확히 지원하지 못하는 추출은 미지원으로 표시하고 제한된 원문과 본문 추출을 구분한다.
오류에 secret·원문 전체를 넣지 않는다. 페이지의 명령은 비신뢰 데이터다.
보안 대상 fixture를 위해 production의 금지 IP 정책을 완화하지 않는다.
