## 안전 계약
기본 꺼짐, 기존 HTTP 프로필의 유한한 명시 순서와 사용자 전송 대상 변경 확인이 필요하다. CLI fallback은 미지원으로 표시한다.
기존 bounded retry가 끝난 뒤 첫 성공 단계 전이며 text/reasoning/tool 조각을 하나도 받지 않은 명시적 HTTP 429·provider 5xx만 전환한다.
취소·인증/권한/입력/capability 오류·부분 stream·연결 유실/timeout·도구 실행 뒤에는 전환하지 않는다.
접수한 후보·전송 identity·가격 기준을 고정하고 실제 사용 전 변경/삭제/비활성·자격 변경을 재검사한다. 후보를 몰래 교체하지 않는다.
DB에 원래 선택·실제 프로필·시도 이력을 함께 보존하며 실제 실행 프로필도 기존 실행 중 편집/secret 교체 차단의 보호를 받는다.
후보마다 capability·입력 용량·시간/token/비용 한도·FAIR·취소를 유지한다. 통화/가격 불일치로 예산을 우회하지 않는다.
재시작은 기존 interrupted/unknown 복구이며 후보를 자동 재호출하지 않는다. Owner·revision·멱등 API, 접수 키, provider 오류 가림·다른 모델의 native 서명 제거를 재사용한다.
로컬 HTTP fixture만 사용하고 새 dependency·외부 계정·실제 유료 모델/서비스 조작은 금지한다.

## 기존 세션 브라우저 인수 후속
기존 `ae49eec`·기준·소유권·유효한 Rust·웹 단위·타입 근거를 보존한다. 기존 세션에서 정확히 `web/e2e/model-fallback.spec.ts`의 선택 실행과 소유 범위의 자기 결함 수정까지 맡는다.
원본 COMMON의 공유 환경·공유 target·전체 명령 flock을 적용한다. 새 설치·다른 검사 중단·포트 변경·타 worktree 동기화는 하지 않는다. 실행 가능한 잔여를 끝내고 외부 실계정·실공급자 검증은 미검증으로 구분한다.
최신 COMMON을 실제 읽고 `grove-handoff:v1`에 실행 가능한 잔여·실제 blocker·통합 담당의 공통 경계 인수를 구분한다. 관련 코드·시험·RESULT만 한국어 로컬 커밋 후 종료하며 메인은 같은 소유 범위를 편집하지 않는다.
